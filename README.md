# PRODIGY_DS_03

## Customer Purchase Prediction Using Decision Tree Classifier

### Objective

Build a Decision Tree Classifier to predict whether a customer will purchase a product or service based on demographic and behavioral data.

### Dataset

Bank Marketing Dataset

The dataset contains customer information such as:

* Age
* Job
* Marital Status
* Education
* Account Balance
* Housing Loan Status
* Previous Marketing Campaign Information

### Tools & Technologies

* Python
* Pandas
* Scikit-learn
* Matplotlib
* Visual Studio Code

### Project Workflow

1. Data Loading and Exploration
2. Data Preprocessing
3. Encoding Categorical Variables
4. Train-Test Split
5. Decision Tree Model Training
6. Model Evaluation
7. Decision Tree Visualization

### Model Performance

Accuracy: 89.58%
